### 38. Live key highlighting via matrix state polling

Uses the standard VIA `id_switch_matrix_state` command (`0x02`, `0x03`) — no firmware changes required. The same command Vial's own Key Tester uses.

**File:** `src/SvalboardLayerViz.Core/Protocol/VialCommands.cs`

- Added `SwitchMatrixState = 0x03` constant

**File:** `src/SvalboardLayerViz.Core/Protocol/IVialProtocolService.cs`

- Added `bool[,] GetSwitchMatrixState(int rows, int cols)` to the interface

**File:** `src/SvalboardLayerViz.Core/Protocol/VialProtocolService.cs`

- Implemented `GetSwitchMatrixState()`: sends `[0x02, 0x03]`, parses response starting at byte 2. Each byte = one row, each bit = one column (bit set = pressed)

**New file:** `src/SvalboardLayerViz.Core/Protocol/MatrixPollingService.cs`

- Background polling at ~10Hz via `Task.Run` + `Task.Delay(100)`
- Fires `MatrixStateChanged` event only when state differs from previous poll
- `PollError` event for diagnostics
- `Start()` / `Stop()` / `IDisposable` lifecycle
- Graceful error handling (device disconnect breaks the loop cleanly)

**File:** `src/SvalboardLayerViz.App/ViewModels/KeyViewModel.cs`

- Added `[ObservableProperty] bool _isPressed` with `[NotifyPropertyChangedFor]` for `BackgroundColor`, `BorderColor`, `ActiveBorderThickness`
- `BorderColor` returns `#FFFFFF` when pressed (bright border glow)
- `ActiveBorderThickness` returns `Avalonia.Thickness(3.0)` when pressed, `(1.5)` normally

**File:** `src/SvalboardLayerViz.App/Views/KeyView.axaml`

- `BorderThickness` bound to `ActiveBorderThickness` (was hardcoded)

**File:** `src/SvalboardLayerViz.App/ViewModels/MainWindowViewModel.cs`

- Creates `MatrixPollingService` on connect when live highlighting is enabled
- `OnMatrixStateChanged` dispatches to UI thread, updates `IsPressed` on all KeyViewModels by matching (row, col)
- `ToggleLiveHighlighting` command starts/stops polling, persists preference
- Stops polling on device disconnect, clears pressed states

**File:** `src/SvalboardLayerViz.Core/Settings/UserSettings.cs`

- Added `LiveKeyHighlighting` (default: true)

**File:** `src/SvalboardLayerViz.App/Views/MainWindow.axaml`

- Added live highlighting toggle button (pulse/heartbeat icon) with opacity toggle pattern, visible when connected
