### 44. Auto-layer-switching via momentary hold detection

**File:** `src/SvalboardLayerViz.App/ViewModels/MainWindowViewModel.cs`

- `_momentaryLayerCache`: `Dictionary<(row,col), targetLayer>` for MO/LT/TT keys, built once from layer 0 on connect
- `_momentaryPressTimestamps`: tracks when each momentary key was first detected as pressed
- `LayerHoldThresholdMs` (default 200ms): minimum hold time before layer switch activates — prevents flicker from quick taps on dual-function keys (e.g., LT — tap for Enter, hold for layer)
- `IsAutoLayerSwitchEnabled` toggle with persistence
- Hold time accumulates across polls using `Environment.TickCount64`
- Highest active layer wins (matching QMK priority)
- Falls back to layer 0 when nothing held

### 45. Toggle (TG) layer tracking via edge detection

**File:** `src/SvalboardLayerViz.App/ViewModels/MainWindowViewModel.cs`

- `_toggleLayerCache`: separate cache for TG keys, built from layer 0
- `_previousMatrixState`: stores last poll's matrix for edge detection
- `_toggledLayers`: `HashSet<int>` of locally toggled-on layers
- Rising edge detection: TG key not-pressed → pressed flips the toggle
- Held keys don't re-trigger (only rising edges count)
- Combined resolve: highest of (momentary held past threshold | toggled on)

**WARNING documented in code:** Toggle state is a best-effort local mirror. Can drift if:
- App starts while a layer is already toggled on
- Very fast double-tap within one poll cycle (~100ms)
- Firmware has complex layer logic (combos, macros)
