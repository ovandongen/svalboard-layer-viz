# Changes — 02-04-26 (Session 4)

## Bug Fixes & Polish

### 51. Settings save preserves unmanaged fields

**File:** `src/SvalboardLayerViz.App/ViewModels/SettingsViewModel.cs`

- `Save()` now loads existing settings first and uses `with { }` to merge, instead of creating a fresh `UserSettings` record
- Previously, fields not managed by the settings window (`AlwaysOnTop`, `LiveKeyHighlighting`, `AutoLayerSwitch`) were silently reset to their defaults on every save
- This was a recurring bug pattern — now structurally prevented for all current and future settings fields

### 52. Refresh button race condition fixed

**File:** `src/SvalboardLayerViz.App/ViewModels/MainWindowViewModel.cs`

- `StopMatrixPolling()` moved to the top of `TryConnect()`, before any device operations
- Previously only called in the "no devices found" early-return path — when a device was found, `KeymapLoader.Load()` would dispose the HID stream while the polling task was still reading from it
- Eliminates the "Key polling error" crash on refresh

### 56. macOS .app bundle

**New directory:** `SvalboardLayerViz.app/`

- `Contents/Info.plist` — bundle metadata, `CFBundleIconFile` pointing to `icon.icns`
- `Contents/Resources/icon.icns` — dock icon
- `Contents/MacOS/run` — shell script launching the self-contained published binary

macOS shows the `dotnet` host process icon in the dock when using `dotnet run`. The `.app` bundle is the only way to get a custom dock icon on macOS. Built via:

```bash
dotnet publish src/SvalboardLayerViz.App -c Release -r osx-arm64 --self-contained -o SvalboardLayerViz.app/Contents/MacOS/bin
```

Published binaries (111MB) are gitignored; the bundle shell (plist, script, icns) is committed.
