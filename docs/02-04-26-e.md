# Changes — 02-04-26 (Session 5)

## Phase 3: Export to PNG / PDF / SVG

### 55. SkiaSharp rendering pipeline

**Files:** `src/SvalboardLayerViz.Core/Export/BoardRenderer.cs`, `KeyStyleResolver.cs`

- Added SkiaSharp 3.116.1 to Core project — single rendering pipeline for all three export formats
- `BoardRenderer` draws a full layer (header + keys) to any `SKCanvas` using the modern `SKFont` API (no deprecation warnings)
- `KeyStyleResolver` extracted from `KeyViewModel` — static helper that computes background, border, text color, and opacity for a key given its layer colors. Shared by both the Avalonia UI and the export renderer, eliminating duplication
- `KeyViewModel` now delegates its `BackgroundColor`, `BorderColor`, `TextColor`, and `KeyOpacity` properties to `KeyStyleResolver.Resolve()`

### 56. Export service with PNG/PDF/SVG support

**Files:** `src/SvalboardLayerViz.Core/Export/ExportService.cs`, `ExportOptions.cs`, `ExportFormat.cs`

- `ExportService.Export()` dispatches to format-specific methods:
  - **PNG:** All selected layers stacked vertically on a single image. 2× scale default for high-DPI. Uses `SKBitmap` + `SKImage.Encode()`
  - **PDF:** Layers packed onto standard pages (A4 or Letter, landscape). Board scaled to fit page width with 30pt margins. Multiple layers per page, flowing to new pages when full. Uses `SKDocument.CreatePdf()` with `SKCanvas.Scale()` + `Translate()`
  - **SVG:** All selected layers stacked vertically. Background drawn as rect (SVG canvas doesn't support `Clear()`). Uses `SKSvgCanvas.Create()`
- `ExportFormat` enum: `Png`, `Pdf`, `Svg`
- `PdfPageSize` enum: `A4Landscape` (841.89 × 595.28 pt), `LetterLandscape` (792 × 612 pt)
- `ExportOptions` record: format, selected layer indices, output path, scale, background color, hide-thumb-clusters map, PDF page size

### 57. Print-friendly color theme

**File:** `src/SvalboardLayerViz.Core/Keymap/LayerColorService.cs`

- Added `printFriendly` parameter to `GetLayerColors()` — when true, generates light pastel key fills, dark borders, and always-dark text
- Default export background changed from dark (`#181825`) to white (`#FFFFFF`)
- User-picked colors are lightened for print; algorithmic colors use bright pastels at 88% lightness
- Transparent keys use very light fill (94% lightness) with gray text
- Saves toner, looks clean on paper

### 58. Hide bottom clusters (thumbs + modifiers)

**File:** `src/SvalboardLayerViz.Core/Export/BoardRenderer.cs`

- Per-layer "Hide thumbs" option omits all bottom-area keys: L-Thumb, R-Thumb, and L-Mod (Ctrl/Tab/Shift/Enter/Fn/Caps)
- These clusters all occupy the same Y=5–6 region; hiding them reduces the layer block height
- Lookup uses `SvalboardLayout` position data keyed by (Row, Col) to determine cluster membership
