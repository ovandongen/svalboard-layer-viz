### 29. Layer color configuration

**File:** `src/SvalboardLayerViz.Core/Keymap/LayerColorService.cs`

- Added `HexToHsl()` and `GetLayerColors(string userHexColor)` overload
- `BuildColors()` now takes `isUserColor` flag: user-picked colors render faithfully as background; algorithmic colors use dark multipliers (`l*0.42`) for dark theme
- Added `TextColor` and `TransparentTextColor` to `LayerColors` record, computed via W3C relative luminance (`GetContrastTextColor()`)
- Auto-contrast: returns `#1E1E2E` (dark) on luminance > 0.4, `#FFFFFF` (white) otherwise

- Constructor accepts optional `userLayerColors` dictionary for computing target layer colors
- Added `HexKeycode` property and `SetLabelCommand` for right-click labeling

**File:** `src/SvalboardLayerViz.App/ViewModels/LayerViewModel.cs`

- Constructor passes `userLayerColors` and `setLabelRequested` callback through to KeyViewModels

### 31. Custom key labels

**File:** `src/SvalboardLayerViz.Core/Keymap/KeycodeService.cs`

- User-defined custom labels now checked **first** in `Resolve()` (right after transparent/empty), overriding all other keycode resolution
- Previously the lookup was at the very end as a fallback — keycodes matching any earlier branch (basic, mod-tap, layer functions, etc.) would never use user labels

**File:** `src/SvalboardLayerViz.App/Views/KeyView.axaml`

- Added right-click context menu with "Set Custom Label..." item bound to `SetLabelCommand`

**File:** `src/SvalboardLayerViz.App/App.axaml.cs`

- Wired `SetKeyLabelRequested` callback: opens a small dialog with keycode info, text input, and Save button
- Saves label directly to settings.json and calls `ApplySettings()` to refresh the display
