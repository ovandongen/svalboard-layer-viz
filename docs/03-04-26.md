### 64. Loc singleton — runtime culture switching

**File:** `src/SvalboardLayerViz.App/Localization/Loc.cs`

- `INotifyPropertyChanged` singleton with string indexer `this[string key]`
- Static shared `_culture` across all Loc instances — solves the dual-instance problem (AXAML `<loc:Loc x:Key="Loc" />` creates a separate instance from `Loc.Instance`)
- `WeakReference<Loc>` list tracks all instances; `SetCulture()` notifies every live instance via `PropertyChanged("Item[]")`, causing all AXAML `{Binding [Key]}` bindings to re-evaluate
- Static `CultureChanged` event for code-behind and ViewModel refresh of computed strings
- `Format(key, args)` helper for interpolated localized strings
- Registered in `App.axaml` as `<loc:Loc x:Key="Loc" />` application resource

### 70. Bugs fixed during implementation
