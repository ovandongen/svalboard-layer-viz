| Key | Left | Top | Width | Height | Z | Shape |

**Trapezoid shapes:** C:2 widens at the bottom by 12px per side (175px top → 199px bottom). Adjacent keys C:0, C:1, C:3 have inner edges that narrow at the bottom to maintain a constant gap with C:2's angled edges. C:1's left edge is shifted inward 5px so the inner edge forms a continuous line with C:0's inner edge. All clip paths use R=14 arc segments at every corner for rounded edges.

**Overlap system:**
- C:2 (ZIndex=0) is the back layer — tall center column
- C:4 (ZIndex=1) "bites" into C:2 via GeometryGroup with EvenOdd fill rule — PathGeometry cutout with rounded corners (R=24) reaches C:2's angled trapezoid edge
- C:5 (ZIndex=2) "punches a hole" in C:2 as an island — second PathGeometry cutout in the same EvenOdd clip
- C:2 label pushed below overlapping keys via Padding="0,240,0,0"

**Shared content template:** `ThumbKeyContent` DataTemplate provides label rendering (SecondaryLabel, DisplayLabel, ShiftedLabel with drop shadows, tooltip, context menu) shared across all 12 creative key elements.

**Code-behind** (`ThumbClusterView.axaml.cs`):

- 1.4× `RenderTransform` (ScaleTransform) for visual enlargement
- Scale origin: left hand from right edge (1.0, 0.5), right hand from left edge (0.0, 0.5) — prevents center overlap

### 87. Creative thumb export rendering

**Modified:** `src/SvalboardLayerViz.Core/Export/BoardRenderer.cs`

- `RenderCreativeThumbCluster()` — renders 6 thumb keys with custom positions, sizes, and Z-ordering using SkiaSharp canvas transforms
- Trapezoid key shapes via `BuildTrapezoidPath()` using `ArcTo` for rounded corners at each vertex
- `GetTrapezoidCorners()` computes 4 corner points: C:2 widens at bottom, adjacent keys narrow at bottom on inner edge
- `TaperEdge` flags enum determines which edges taper per key and hand
- `BuildC2ClipPath()` creates EvenOdd SKPath with:
  - Padded trapezoid outer boundary (5px outward to prevent stroke clipping)
  - C:4 bite cutout extending to C:2's angled edge (interpolated at y=190 and y=310)
  - C:5 island hole cutout
- Stroke width compensation: `1.5 / (csx * 1.4)` matches normal key stroke width after canvas scaling. C:2 uses `2.0 / scale` for its long angled edges
- Canvas transform chain: Translate → Scale(1.4) with edge origin → Scale(clusterW/880, clusterH/435)
- Font sizes 26/36/28 for secondary/primary/shifted labels (compensating for Viewbox shrink + RenderTransform scale)

### 89. SVG export truncation fix

**Modified:** `src/SvalboardLayerViz.Core/Export/ExportService.cs`

- Changed `File.OpenWrite` → `File.Create` in all three export methods (PNG, PDF, SVG)
- `File.OpenWrite` doesn't truncate, so re-exporting to the same file with fewer layers left stale XML at the end, causing SVG parse errors ("Extra content at the end of the document")
