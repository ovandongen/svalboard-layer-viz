## Transparency Fallback for Windows Compatibility

### 90. Transparency compositing fallback

**Modified:** `src/SvalboardLayerViz.App/Views/MainWindow.axaml.cs`

- On some Windows 11 systems, the combination of `TransparencyLevelHint="Transparent"` + `Background="Transparent"` + `SystemDecorations="None"` causes the window to be completely invisible when the compositor can't provide transparency
- Added a check in the `Opened` handler: if `ActualTransparencyLevel` is `None`, the window falls back to a solid black background and re-enables `SystemDecorations.Full` (OS title bar and resize handles)
- Systems that support transparency are unaffected — the check only triggers when compositing fails
- Addresses user report: app starts but only shows a tray icon and task manager process, no visible window (Windows 11, v1.3.0)
