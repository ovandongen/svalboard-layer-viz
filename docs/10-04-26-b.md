# Changes — 10-04-26-b (Session 12)

## Phase 4a Session 2 — Keycode Descriptor, Encoder, Decoder & Catalog

### 122. KeycodeDescriptor type system

**New file:** `src/SvalboardLayerViz.Core/Keymap/KeycodeDescriptor.cs`

- Abstract record `KeycodeDescriptor` with 10 concrete variants: `NoKeycode`, `TransparentKeycode`, `BasicKeycode(BaseCode)`, `ModifiedKeycode(Mods, BaseCode)`, `ModTapKeycode(Mods, BaseCode)`, `LayerTapKeycode(Layer, BaseCode)`, `LayerModKeycode(Layer, Mods)`, `LayerFunctionKeycode(Kind, Layer)`, `OneShotModKeycode(Mods)`, `CustomKeycodeDescriptor(Index)`, `RawKeycode(Value)`
- `ModFlags` — `[Flags] enum` with Ctrl/Shift/Alt/Gui/Right bits matching QMK's 5-bit modifier encoding
- `LayerFunctionKind` — enum with TO/MO/DF/TG/OSL/TT variants
- Named `CustomKeycodeDescriptor` (not `CustomKeycode`) to avoid collision with existing `Models.CustomKeycode`

### 123. KeycodeEncoder — descriptor to raw keycode

**New file:** `src/SvalboardLayerViz.Core/Keymap/KeycodeEncoder.cs`

- `KeycodeEncoder.Encode(KeycodeDescriptor) → ushort` — static method using pattern-matched switch expression
- Covers all QMK encoding ranges: basic, modified, mod-tap, layer-tap, layer-mod, layer functions (TO/MO/DF/TG/OSL/TT), one-shot mod, custom, raw passthrough
- Inverse of `KeycodeDecoder.Decode`

### 124. KeycodeDecoder — raw keycode to descriptor

**New file:** `src/SvalboardLayerViz.Core/Keymap/KeycodeDecoder.cs`

- `KeycodeDecoder.Decode(ushort) → KeycodeDescriptor` — static method that classifies any 16-bit QMK keycode into the correct descriptor variant
- Range constants kept in sync with `KeycodeService` (now shared via the same encoding logic)
- Unknown/unmapped keycodes fall through to `RawKeycode(value)` — no exceptions, always returns a valid descriptor

### 125. KeycodeCatalog — single source of truth for keycode data

**New file:** `src/SvalboardLayerViz.Core/Keymap/KeycodeCatalog.cs`

- 12 grouped `IReadOnlyList<CatalogEntry>` lists: Letters, Numbers, Punctuation, Editing, Navigation, FunctionKeys, LockKeys, Numpad, Modifiers, MouseKeys, Media, Special
- `CatalogEntry(Code, Label, ShiftedLabel?)` record — carries the raw code, display label, and optional shift symbol
- Derived `BasicKeycodes` and `ShiftedSymbols` dictionaries built lazily from catalog groups
- `AllGroups` property for iteration by future key picker UI
- Data migrated from inline dictionaries in `KeycodeService.cs`

### 126. KeycodeService refactored to use Decoder + Catalog

**Modified:** `src/SvalboardLayerViz.Core/Keymap/KeycodeService.cs`

- Removed ~90 lines of inline `BasicKeycodes` and `ShiftedSymbols` dictionaries and ~20 QMK range constants
- `Resolve()` now calls `KeycodeDecoder.Decode()` then pattern-matches the descriptor to build `KeycodeInfo`
- Label lookups use `KeycodeCatalog.BasicKeycodes` and `KeycodeCatalog.ShiftedSymbols`
- Modifier formatting uses `ModFlags` enum with `HasFlag()` instead of raw bit checks
- Extracted `ResolveLayerFunction`, `ResolveCustom`, `ResolveModified` helper methods
- All 334 existing tests pass unchanged — output is identical

### 127. Encoder and decoder tests
