## Phase 4a Session 3 — Edit Session & Edit Operations

### 128. EditOp — abstract edit operation record

**New file:** `src/SvalboardLayerViz.Core/Keymap/EditOp.cs`

- Abstract record `EditOp` with one concrete subtype: `SetKeyOp(Layer, Row, Col, OldCode, NewCode)`
- Carries both old and new values to support undo/redo without external state

### 129. DeviceWrite — device write command records

**New file:** `src/SvalboardLayerViz.Core/Keymap/DeviceWrite.cs`

- Abstract record `DeviceWrite` with two subtypes: `SetKeycodeWrite(Layer, Row, Col, Keycode)` and `KeymapBufferWrite(Offset, Data)`
- Built from pending edits by `KeymapEditSession.BuildDeviceWrites()`

### 130. KeymapEditSession — in-memory edit state with undo/redo

**New file:** `src/SvalboardLayerViz.Core/Keymap/KeymapEditSession.cs`

- Constructor clones baseline `ushort[,,]` so original array is never mutated
- `Apply(EditOp)` pushes to undo stack, clears redo stack, executes forward
- `Undo()` / `Redo()` move ops between stacks with forward/reverse execution
- `Discard()` copies baseline back to current state, clears both stacks
- `HasPendingChanges` / `PendingChanges` compare current vs baseline (not undo history) — a key changed then reverted produces no pending writes
- `BuildDeviceWrites()` emits one `SetKeycodeWrite` per changed key
- `FromSnapshot(ushort[] flat, int layers, int rows, int cols)` factory for restore flows
- `GetCurrent(l, r, c)` / `GetBaseline(l, r, c)` accessors

## Phase 4a Session 4 — Diagnostic Logging

### 132. DiagnosticLog — subsystem-tagged logging system

**New file:** `src/SvalboardLayerViz.Core/Diagnostics/DiagnosticLog.cs`

- Replaces `StartupLogger` with subsystem-tagged API: `Write(LogLevel, subsystem, message)`
- Convenience methods: `Trace()`, `Debug()`, `Info()`, `Warn()`, `Error()`
- `LogLevel` enum: Trace, Debug, Info, Warn, Error
- Runtime-adjustable minimum level via `SetMinimumLevel()` / `MinimumLevel`
- File rotation at 2 MB (`MaxLogSize`), keeps one `.log.1` backup

- `CollectDiagnosticReport()` returns formatted string with header, environment info, last 100 log lines
- `GetLogDirectory()` / `GetLogFilePath()` for UI integration
- Log format: `[2026-04-10 12:34:56.789] INFO  [Startup] message`
