# Changes — 10-04-26-d (Session 14)

## Phase 4a Session 6 — Snapshot History Service

### 138. KeyboardId — device identity for snapshot matching

**New file:** `src/SvalboardLayerViz.Core/History/KeyboardId.cs`

- Sealed record `KeyboardId(VendorId, ProductId, Uid)` — all strings, hex-formatted
- `From(int vendorId, int productId, ulong vialUid)` factory pads to fixed widths (4/4/16 hex chars)

### 139. SnapshotCompatibility — matching snapshots to devices

**New file:** `src/SvalboardLayerViz.Core/History/SnapshotCompatibility.cs`

- `SnapshotCompatibility` enum: `Exact` (VID+PID+UID match), `Firmware` (VID+PID match, UID differs), `None` (VID or PID differs)
- `SnapshotCompatibilityChecker.Check(snapshot, device)` — pure static comparison

### 140. KeymapSnapshot — point-in-time keymap capture

**New file:** `src/SvalboardLayerViz.Core/History/KeymapSnapshot.cs`

- Sealed record with schema version, timestamp, reason, keyboard ID, dimensions, flat keycode array
- `SnapshotReason` enum: `PreSave`, `PostSave`, `Manual`, `FirstConnect` (JSON string-serialized)
- `ToKeymap()` reconstitutes flat array into 3D `ushort[,,]`
- `FlattenKeymap(ushort[,,])` static helper for serialization

### 141. SnapshotMetadata — lightweight listing without loading keycodes

**New file:** `src/SvalboardLayerViz.Core/History/SnapshotMetadata.cs`

- Sealed record carrying file path, timestamp, reason, keyboard ID, device name, dimensions
- Used by `ListAsync` to avoid deserializing full keymap data for browsing

### 142. ISnapshotService — snapshot service interface

**New file:** `src/SvalboardLayerViz.Core/History/ISnapshotService.cs`

- `CaptureAsync`, `ListAsync`, `LoadAsync`, `DeleteAsync`, `ExportAsync`, `PruneAsync`, `GetSnapshotDirectory`
- Prune accepts `maxSaveSnapshots` and `keepFirstConnectDays` parameters

### 143. SnapshotService — JSON file-based storage with retention pruning

**New file:** `src/SvalboardLayerViz.Core/History/SnapshotService.cs`

- Stores snapshots as JSON in `{AppData}/SvalboardLayerViz/snapshots/`
- Filenames include milliseconds + 6-char GUID suffix to prevent collisions
- `CaptureAsync` creates snapshot, flattens keymap, writes JSON
- `ListAsync` optionally filters by keyboard ID (includes `Firmware` compatibility matches)
- `PruneAsync` retention: manual = keep all, pre/post-save = keep last N, first-connect = keep within N days
- Uses `DiagnosticLog` for capture/delete/prune logging
- JSON options: camelCase naming with case-insensitive deserialization for round-trip safety

### 144. SnapshotDiffComputer — compare two keymaps

**New file:** `src/SvalboardLayerViz.Core/History/SnapshotDiffComputer.cs`

- `Diff(from, to)` compares two 3D keymaps, returns `KeyDiff` records for changed keys
- `ToEditOps(diffs)` converts diffs into `SetKeyOp` instances for replay through `KeymapEditSession`
- Throws `ArgumentException` on mismatched dimensions

### 145. Snapshot settings

**Modified:** `src/SvalboardLayerViz.Core/Settings/UserSettings.cs`

- Added `FirmwareLenientMatch` (bool, default false) — allows restoring from different UID
- Added `KeepFirstConnectDays` (int, default 30) — first-connect snapshot retention window

### 148. Six keycode builders

- **CustomKeycodeBuilder** — 1 slot (index) → `CustomKeycodeDescriptor`
- All builders validate `CanBuild` before allowing `Build()`, throw on out-of-range slots
