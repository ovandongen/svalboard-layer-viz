## Phase 4a Sessions 8+9 — Unlock Dialog + Key Picker Dialog

### 153. UnlockDialogViewModel — poll-based unlock flow

**New file:** `src/SvalboardLayerViz.App/ViewModels/UnlockDialogViewModel.cs`

- `MiniKeyDisplay` record with `X`, `Y`, `W`, `H`, `IsHighlighted`, `Label`, computed `Background` color string
- Constructor takes `IVialProtocolService` + optional `Func<TimeSpan, Action, IDisposable>` timer factory for testability
- `BeginAsync()` — checks `GetUnlockStatus()` via Task.Run; if already unlocked, fires `UnlockCompleted` immediately; otherwise maps `KeysToHold` to mini-board positions from `SvalboardLayout.GetKeyPositions()`, calls `UnlockStart()`, starts 250ms poll timer
- Poll tick guards against overlapping polls with `_pollInFlight` bool; on `UnlockPoll() == true` → stops timer, sets `IsUnlocked`, fires `UnlockCompleted`
- `CancelCommand` stops polling, fires `Cancelled` callback
- Mini-board renders all 60 key positions at 18px/unit scale with 14px key squares
- Default timer uses `System.Threading.Timer`; production callers inject `DispatcherTimer`-based factory

### 157. KeyPickerDialog — 4-step wizard AXAML view

**New files:** `src/SvalboardLayerViz.App/Views/KeyPickerDialog.axaml`, `KeyPickerDialog.axaml.cs`

- Window: 550×520, CenterOwner, non-resizable
- Footer: Back (visible when `CanGoBack`), Cancel, Next (visible on Arguments step), Apply (visible on Preview step)
- **Step 1 (Category):** `WrapPanel` with 6 styled buttons (140×60) for Basic/Modifier/Layer/Media/Custom/Advanced, each passing `PickerCategory` enum via `CommandParameter`
- **Step 2 (Selection):** Two sub-panels switched by `IsCatalogMode`/`IsBuilderMode`:
  - Catalog mode: `TextBox` for search + `WrapPanel` of 64×36 keycode buttons from `FilteredCatalog`, binding up to parent `SelectCatalogEntryCommand`
  - Builder mode: `ItemsControl` listing `AvailableBuilders` with `DisplayName` buttons → `SelectBuilderCommand`
- **Step 3 (Arguments):** `SlotsPanel` StackPanel populated by code-behind `RebuildSlotsUi()`:
  - `ArgumentKind.BasicKey` → ComboBox from KeycodeCatalog entries
  - `ArgumentKind.Modifiers` → WrapPanel with Ctrl/Shift/Alt/Gui CheckBoxes → `ModFlags`
  - `ArgumentKind.Layer` → NumericUpDown (0–15)
  - `ArgumentKind.LayerFunctionKind` → ComboBox (TO/MO/DF/TG/OSL/TT)
  - `ArgumentKind.CustomIndex` → NumericUpDown (0–31)
  - Preview label shown when `ActiveBuilder.CanBuild`
- **Step 4 (Preview):** Advanced raw hex TextBox (parsed in code-behind via `SetRawKeycode`), preview display with `PreviewLabel` (20pt bold) + `PreviewRawCode` (hex), recently-used row (top 10, rendered as buttons)
- Code-behind: subscribes to `PropertyChanged` to rebuild slot UI on step/builder changes, handles `RawHexInput.TextChanged` for hex parsing, dynamically populates recently-used panel
