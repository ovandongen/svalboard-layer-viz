### 119. Write and unlock implementations in VialProtocolService

**Modified:** `src/SvalboardLayerViz.Core/Protocol/VialProtocolService.cs`

- `SetKeycode` — sends `[0x05, layer, row, col, kc_hi, kc_lo]` with big-endian keycode encoding
- `KeymapSetBuffer` — sends `[0x13, offset_hi, offset_lo, size, ...payload]` with max payload size validation
- `DynamicKeymapReset` — sends `[0x06]`
- `EepromReset` — sends `[0x0A]`
- `GetUnlockStatus` — sends `[0xFE, 0x05]`, parses response: byte 0 = unlocked, byte 1 = in-progress, bytes 2+ = (row, col) pairs terminated by 0xFF/0xFF or zero-padding
- `UnlockStart` — sends `[0xFE, 0x06]`
- `UnlockPoll` — sends `[0xFE, 0x07]`, returns `response[0] != 0`
- `Lock` — sends `[0xFE, 0x08]`
