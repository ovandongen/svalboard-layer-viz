### 209. SnapshotDiffDialogViewModel

**New file:** `src/SvalboardLayerViz.App/ViewModels/SnapshotDiffDialogViewModel.cs`

- Core VM for the diff dialog. Contains `DiffLineViewModel` and `DiffMiniKeyDisplay` records.
- Constructor: takes `KeymapSnapshot`, optional device keymap, keyboard ID, and `KeycodeService`. Computes diffs via `SnapshotDiffComputer.Diff(device, snapshot)` — direction is device→snapshot so `SetKeyOp` values are correct for restore.
- `TruncateToMinLayers` private helper handles layer count mismatch before diffing; sets warning banner when snapshot has more layers than device.
- `DiffMiniKeyDisplay` uses orange `#FAB387` for changed keys (vs. red `#F38BA8` in UnlockDialog's `MiniKeyDisplay`) to visually differentiate diff highlights.
- Layer sync: changing one side's layer selector syncs the other when `SyncLayers` is true; `RebuildMiniBoards()` called on every layer change.
- `RestoreAsync` command: builds `KeymapEditSession(deviceKeymap)`, applies `ToEditOps(diffs)`, fires `RestoreCompleted` callback then `CloseRequested`.
- Firmware mismatch detection: compares snapshot's `KeyboardId.Uid` against current device's — shows `Diff_FirmwareWarning` banner if different.
- `MaxLayerIndex` property (= `LayerCount - 1`) for correct NumericUpDown binding (avoids off-by-one).

### 217. Bugfixes from E2E testing

**Modified:** `src/SvalboardLayerViz.App/ViewModels/MainWindowViewModel.cs`, `src/SvalboardLayerViz.App/Views/SnapshotDiffDialog.axaml`, `src/SvalboardLayerViz.App/ViewModels/SnapshotDiffDialogViewModel.cs`

Five fixes found during manual E2E testing:

1. **Repeat-restore silently blocked** — `RestoreFromSnapshot` had `if (IsEditMode) return;` which blocked the second restore because after Save, edit mode stays active. Fix: if already in edit mode, cleanly discard the old session first, then activate the new one.
2. **NumericUpDown too narrow** — `Width="80"` was too tight for the `'L'0` format string. Widened to `Width="100"`.
3. **NumericUpDown Maximum off-by-one** — `Maximum` was bound to `LayerCount` (count) instead of max valid index. Added `MaxLayerIndex` property (`LayerCount - 1`).
4. **Mini-boards truncated at initial layout** — Canvas was fixed at 440x140 inside a `*`-width column. Wrapped in `Viewbox Stretch="Uniform"`.
5. **Disabled Restore tooltip invisible** — Avalonia 11.3 doesn't fire tooltips on disabled controls. Wrapped button in a `Panel` carrying the tooltip.
6. **NumericUpDown text top-aligned** — Added `Height="26" Padding="4,2" VerticalContentAlignment="Center"` for compact, centered appearance.
