### 251. VialProtocolService macro implementations

**Modified:** `src/SvalboardLayerViz.Core/Protocol/VialProtocolService.cs`

- `GetMacroCount`: simple command pattern — send `[0x0C]`, return `response[1]`
- `GetMacroBufferSize`: send `[0x0D]`, return BE16 from `response[1..2]`
- `GetMacroBuffer`: chunked read loop cloned from `GetKeymapBuffer` — send `[0x0E, offset_hi, offset_lo, chunkSize]`, copy from `response[4]`, return raw `byte[]`
- `MacroSetBuffer`: chunked write cloned from `KeymapSetBuffer` — `[0x0F, offset_hi, offset_lo, size, ...payload]` with `PayloadSize` guard
- `DynamicKeymapMacroReset`: one-liner, send `[0x0B]`
