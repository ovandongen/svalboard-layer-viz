## Macro codec rewrite — old QMK format to new SS_QMK_PREFIX

### 280. MacroCodec rewrite to new SS_QMK_PREFIX format

**Modified:** `src/SvalboardLayerViz.Core/Macros/MacroCodec.cs`

- Complete rewrite from old QMK format (`0x01 kc` = tap) to new SS_QMK_PREFIX format
- New encoding: tap = `0x01 0x01 kc` (3 bytes), down = `0x01 0x02 kc`, up = `0x01 0x03 kc`, mod-tap = `0x01 0x05 kc mods` (4 bytes), delay = `0x01 0x04 digits |` (pipe terminator), text = raw ASCII
- Constants: `SsQmkPrefix=0x01`, `SsTapCode=0x01`, `SsDownCode=0x02`, `SsUpCode=0x03`, `SsDelayCode=0x04`, `SsModTapCode=0x05`, `DelayTerminator=(byte)'|'`
- Removed old `prevWasDelay` digit-escaping logic, `IsPrefix` helper, `ComputeTextSize` helper
- `ComputeEncodedSize` updated: tap/down/up=3, mod-tap=4, delay=2+digits+1
- Old format caused "invalid keystring" in keybard — text actions fired but tap actions didn't arrive

### 281. MacroModTapAction record type

**Modified:** `src/SvalboardLayerViz.Core/Macros/MacroAction.cs`

- Added `MacroModTapAction(byte Keycode, byte Mods)` record for SS_MOD_TAP (action type 0x05)
- Mods bitmask: bit0=Ctrl, bit1=Shift, bit2=Alt, bit3=Gui, bit4=RCtrl, bit5=RShift, bit6=RAlt, bit7=RGui

### 282. MacroCodecTests rewrite

**Modified:** `src/SvalboardLayerViz.Tests/Macros/MacroCodecTests.cs`

- Complete rewrite for new format — all assertions updated to match SS_QMK_PREFIX byte sequences
- Added mod-tap encode/decode tests, round-trip tests with mod-tap actions
- Tests verify 4-byte mod-tap encoding: `01 05 kc mods`
