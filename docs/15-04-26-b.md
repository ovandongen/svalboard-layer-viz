## Phase 4d — Combos + Tap Dance

Plan file: `/Users/user/.claude/plans/radiant-cuddling-axolotl.md`. Adds per-entry editing for two Vial dynamic features: N-key combos (chord → keycode) and tap-dance (1 key → different output per tap/hold variant). Reuses existing edit-session, save, snapshot, and picker infrastructure. Ships as five slices (S1–S5).

### 303. S1 — Protocol methods + dynamic-entry codecs

**New files:** `src/SvalboardLayerViz.Core/Dynamic/ComboEntry.cs`, `src/SvalboardLayerViz.Core/Dynamic/TapDanceEntry.cs`

**Modified:** `src/SvalboardLayerViz.Core/Protocol/IVialProtocolService.cs`, `src/SvalboardLayerViz.Core/Protocol/VialProtocolService.cs`

### 306. S4 — Combo + TapDance editor dialogs + wiring

**New files:** `src/SvalboardLayerViz.App/ViewModels/ComboEditorViewModel.cs`, `src/SvalboardLayerViz.App/ViewModels/TapDanceEditorViewModel.cs`, `src/SvalboardLayerViz.App/Views/ComboEditorDialog.axaml` (+ codebehind), `src/SvalboardLayerViz.App/Views/TapDanceEditorDialog.axaml` (+ codebehind), `src/SvalboardLayerViz.Tests/ViewModels/ComboEditorViewModelTests.cs`, `src/SvalboardLayerViz.Tests/ViewModels/TapDanceEditorViewModelTests.cs`

- Two new editors follow the live-staging pattern from `QmkSettingsTabViewModel` — every edit (slot pick, tapping-term change, clear) streams a `SetComboOp` / `SetTapDanceOp` into the edit session immediately rather than going through an explicit Save/Cancel buffer. - Combo editor: 4 input slots (inputs use categories `{Basic, Modifier}`) + 1 output slot (output uses `{Basic, Modifier, Layer, Media, Mouse, Macro, Custom, Advanced}`). Clear resets a row via an emitted `SetComboOp` with `Empty` bytes.
- Tap-Dance editor: 4 keycode slots + tapping-term NumericUpDown. Initial-load term writes are suppressed via a `_suppressTermCallback` flag so hydrating from device state doesn't mark the session dirty. Default term is `TapDance.DefaultTappingTerm` (200 ms).
- `MainWindowViewModel`: `OpenCombosCommand` / `OpenTapDanceCommand`, `ApplyComboEdit` / `ApplyTapDanceEdit` (sequence-equal guard prevents no-op ops), `GetCurrentCombos` / `GetCurrentTapDances` (edit-session live state falling back to `KeyboardConfig`). `ComputeDirtyCount` now includes pending combo + tap-dance changes.
- `App.axaml.cs` wires each dialog's `RequestKeyPick` to a fresh `PickerSessionViewModel`, reusing the edit-mode banner's picker flow.
- `MainWindow.axaml` banner gets two new buttons (C, TD) next to Macros/Settings when edit mode is active.
- 40+ new i18n keys (en + nl) for the two dialogs and banner tooltips: `ComboEditor_*`, `TapDanceEditor_*`, `Tooltip_Combos`, `Tooltip_TapDance`, `Common_Clear`.
- 16 VM tests mirror the `MacroEditorViewModelTests` shape: constructor populates rows, edit stages op, read-only blocks edits, clear resets, usage label reflects count.
