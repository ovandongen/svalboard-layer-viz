### 302. Right-modifier support in key picker

**Modified:** `src/SvalboardLayerViz.App/ViewModels/PickerSessionViewModel.cs`, `src/SvalboardLayerViz.App/Views/KeyPickerDialog.axaml`, `src/SvalboardLayerViz.App/ViewModels/MacroEditorViewModel.cs`

- Added `ModRight` observable + "Right" checkbox (16px left margin for separation from Ctrl/Shift/Alt/Gui). QMK's modified-keycode mod field has a single shared Right bit — one keycode can't encode L+R mix — so a single toggle matches the encoding exactly. `CollectModFlags` ORs in `ModFlags.Right` when `ModRight` is set and at least one mod is selected.
- `FormatModPrefix` prefixes names with `R` when `ModFlags.Right` is set (e.g. "RCtrl+RShift").
- `MacroEditorViewModel.KeycodeToMacroTap`: fixed 5-bit picker mod field → 8-bit macro mods byte conversion. Keycode layout `{Right, G, A, S, C}` (bit 4 = right) maps to macro byte where bits 0–3 are left CSAG and bits 4–7 are right CSAG. When the Right bit is set the 4-bit CSAG group is shifted to the upper nibble.
